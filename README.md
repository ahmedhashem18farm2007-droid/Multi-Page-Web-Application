## My Anime

My Anime is an anime website that allows users to explore anime information, view ratings, browse detailed descriptions, and interact with a table that supports adding, deleting, and editing data using JavaScript.

The project includes multiple pages such as a homepage, rating table, login page, and detailed anime information pages.

## Homepage

Navigation bar with links to other pages

Anime world gallery

Search input

footer with contact information

## Rating Page

Navigation bar with links to other pages

Table that displays anime name, ID and rating

Add rows

Delete rows

Edit data

## Login Page

Email + Password inputs

(Remember me) checkbox

(Forgot Password) link

Button to sign in

Link to create a new account

## Register Page 
First name & Last name

Email

Date of birth

Gender (Male / Female)

Sign Up button

## Anime Details Page

Navigation bar with links to other pages

Large anime poster

Information: number of episodes, seasons, premiere year and source

Neat cards showing anime stats
